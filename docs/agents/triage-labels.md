# Метки triage

Навыки используют пять стандартных ролей triage. В этом репозитории им соответствуют следующие метки:

| Роль в mattpocock/skills | Метка в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задачу нужно оценить сопровождающему |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для агента |
| `ready-for-human` | `ready-for-human` | Для реализации нужен человек |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Если навык упоминает triage-роль, используйте соответствующую метку из таблицы.
