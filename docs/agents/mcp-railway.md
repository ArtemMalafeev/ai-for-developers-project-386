# MCP Railway

Для деплоя используется Railway MCP-сервер, запускаемый командой `railway mcp`.

1. Установите Railway CLI.
2. Выполните `railway login` для входа через OAuth или задайте `RAILWAY_API_TOKEN` в окружении.
3. Создайте локальный `.codex/config.toml` в конфигурации Codex; этот файл не хранится в репозитории.
4. Запустите агента в корне репозитория и попросите выполнить деплой.

Токены и файлы с OAuth-сессией не добавляются в Git. Для приложения достаточно переменной `PORT`, которую Railway задаёт при запуске сервиса.
