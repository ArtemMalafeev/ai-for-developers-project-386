# Доменные документы

Перед исследованием кода инженерные навыки должны прочитать:

- `GLOSSARY.md` в корне репозитория.
- `docs/adr/` и ADR, относящиеся к изменяемой области.

Если этих файлов нет, продолжайте работу молча. Создавайте их при необходимости через навык domain modeling, когда нужно зафиксировать термин или решение.

## Структура файлов

Это репозиторий с одним контекстом (single-context):

```
/
├── GLOSSARY.md
├── docs/adr/
└── src/
```

## Терминология и ADR

Используйте термины из глоссария в названиях задач, предложениях по рефакторингу, гипотезах и тестах. Если нужного термина нет, зафиксируйте это для domain modeling. Явно сообщайте о конфликте с существующим ADR, а не переопределяйте его молча.
