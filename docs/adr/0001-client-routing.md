# ADR 0001: Клиентская маршрутизация через vue-router

- Статус: Принято
- Дата: 2026-11-08

## Контекст

Главная страница должна вести в раздел записи и админку. На момент решения приложение состояло из одного стартового компонента, поэтому маршруты и страницы нужно было определить с нуля.

## Решение

Использовать `vue-router` с history mode и маршрутами `/`, `/booking` и `/admin`. Неизвестные URL перенаправлять на главную. Разделы записи и админки на первом этапе представлены страницами-заглушками с общей шапкой приложения.

## Последствия

- Навигация остаётся типобезопасной и единообразной для всех страниц.
- Заглушки можно заменить полноценными представлениями без изменения ссылок главной страницы.
- Для production-сервера потребуется fallback на `index.html` для history mode.
