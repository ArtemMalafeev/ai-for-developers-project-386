## Сценарий использования

1. Владелец — создание типа встречи

Владелец открывает приложение и создаёт тип встречи, указав название, описание и длительность (например, «Совещание», 30 минут).

Созданный тип встречи становится доступен пользователям для записи.

Доступные слоты рассчитываются автоматически на основе рабочего графика владельца, длительности выбранного типа встречи и фиксированного шага стартов.

2. Пользователь — запись на встречу

Пользователь открывает страницу записи без регистрации.

Выбирает один из созданных владельцем типов встречи.

Переходит к календарю на ближайшие 14 дней, включая сегодняшний.

Выбирает дату и свободное время из доступных слотов.

Подтверждает запись.

Приложение сохраняет встречу в локальном хранилище. Выбранное время становится недоступным для других записей.

3. Владелец — просмотр записей

Владелец открывает список запланированных встреч.

Видит все записи независимо от типа встречи.

Каждая запись содержит тип встречи, дату, время начала и окончания.
