# Запись на звонок

Сервис помогает владельцу публиковать доступное время, а гостю выбирать слот для встречи.

## Участники

**Владелец**:
Человек, который создаёт типы встреч, настраивает доступное время и просматривает записи.
_Avoid_: Администратор, организатор

**Гость**:
Человек, который выбирает тип встречи и свободный слот для записи на звонок.
_Avoid_: Пользователь, клиент

## Встречи

**Запись на звонок**:
Выбранный гостем слот для встречи с владельцем.
_Avoid_: Бронирование, заявка
